# Landing

Landing page sections for Aria's marketing site.

| File | Purpose |
|---|---|
| `Landing.jsx` | Composes all landing sections |
| `Hero.jsx` | Wraps `HeroGeometric` + `ChatPreview` |
| `ChatPreview.jsx` | Animated chat mockup below the hero |
| `Navbar.jsx` | Fixed top nav with logo and Get Started |
| `Features.jsx` | Six use-case cards with lucide icons |
| `HowItWorks.jsx` | Connect → Chat → Done steps |
| `CTASection.jsx` | Bottom call-to-action |
| `Footer.jsx` | Logo and copyright |

CTAs say **Get Started** (email + Google auth wired in a later step).
