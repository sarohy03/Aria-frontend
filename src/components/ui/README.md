# UI

Shared, reusable UI primitives used across pages.

| File | Purpose |
|---|---|
| `Button.jsx` | Rounded button with `primary`, `secondary`, and `ghost` variants |
| `Logo.jsx` | Aria lightning-bolt mark + wordmark (uses `/favicon.svg`) |
| `shape-landing-hero.jsx` | Animated geometric hero with framer-motion floating shapes |

Depends on `@/lib/utils` (`cn` helper), `framer-motion`, and `lucide-react`.
